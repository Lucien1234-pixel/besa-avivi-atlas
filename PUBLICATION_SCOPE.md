# Publication Scope

This repository is a public marker of provenance only.

## Published Here

- project name
- public authorship and stewardship notice
- high-level project description
- SHA-256 hash of the private final delivery ZIP
- legal and licensing boundary notes
- third-party rights notice

## Not Published Here

The following materials are deliberately excluded because they could enable copying, reconstruction, plagiarism, or unauthorized redistribution:

- private source package
- atlas datasets
- CSV files
- JSON files
- SVG master files
- PNG previews
- generation or build scripts
- product web build
- audit build
- internal research documentation
- checkpoint archives
- file manifests exposing internal structure
- full checksum lists for unpublished files

## Rationale

The public repository preserves a timestamped public claim and an integrity anchor while keeping the reconstructive materials private.

This approach is intended to reduce plagiarism risk while still documenting that a private, verifiable project package exists.
